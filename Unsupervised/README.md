# Wine Quality Analysis

Unsupervised learning analysis on the red wine quality dataset.

## Files
- `Wine Quality.ipynb` - main notebook with the analysis
- `Wine Quality Analysis.pdf` - exported report
- `winequality-red.csv` - dataset

## Tools used
Python, Pandas, Scikit-learn, Matplotlib

## How to run
Open the notebook in Jupyter or VS Code and run all cells.
